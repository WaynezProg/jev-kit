# Security and data handling

This package sends supplied task text to TypeSafe for model judgments. Do not include secrets or unauthorized material in inputs. Keep API keys and receipts outside the repository.

Judgments are advisory. Do not use confidence, source support, or CLI success as an authorization boundary. Prompt framing and tests do not establish immunity to prompt injection.

Local installers preserve other host settings and create private backups, which can contain credentials for unrelated services. Never attach these backups to issues.

For a suspected vulnerability, use the repository's private vulnerability reporting feature. Do not put credentials or private source text into public issues. Include a minimal synthetic reproduction and affected version.
